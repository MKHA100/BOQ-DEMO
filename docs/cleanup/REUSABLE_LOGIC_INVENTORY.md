# Reusable Logic Inventory

These files remain available only in the untouched original ZIP unless marked as retained. None of the removed workflow code is active in the clean runtime.

| Original path | What it does | Coupling | Dependencies | Reuse risk | Recommended future extraction |
|---|---|---|---|---|---|
| backend/app/pdf_processing/pdf_metadata_reader.py | Reads PDF metadata and page information. | Mostly generic, but expects the existing storage/path model. | PyMuPDF, current project service. | PDF validation rules may be too permissive or too coupled to current upload behavior. | Extract behind a new PdfDocumentReader interface and add isolated unit tests. |
| backend/app/pdf_processing/pdf_renderer.py | Renders PDF pages to images. | Generic rendering core with current naming/output assumptions. | PyMuPDF, Pillow, storage paths. | DPI, rotation, memory usage, and output naming need new-system decisions. | Move rendering into an adapter that returns bytes/metadata instead of writing workflow records directly. |
| backend/app/pdf_processing/pdf_page_service.py | Coordinates rendering, page persistence, thumbnails, and URLs. | Tightly coupled orchestration. | Renderer, database pdf_pages table, storage service. | Reusing whole service would reintroduce old tables and side effects. | Reuse only the renderer; rewrite orchestration for the new data model. |
| backend/app/image_processing/image_format_converter.py | Converts image formats for processing. | Generic. | Pillow. | Color mode and transparency handling require validation. | Extract as a stateless utility with explicit input/output contracts. |
| backend/app/image_processing/image_quality_checker.py | Checks image dimensions/quality. | Partly generic. | Pillow and old quality thresholds. | Old thresholds may not match the future workflow. | Reuse algorithms only after defining new acceptance criteria. |
| frontend/features/pdf-viewer/ | PDF viewing, navigation, zoom, and canvas logic. | Reusable UI foundation but tied to old service types and pdfjs configuration. | pdfjs-dist, old PdfPage contracts. | Bundle size, worker configuration, and old API assumptions. | Rebuild as a new isolated viewer package and import only after the new UX is defined. |
| frontend/features/selection-tools/ | Rectangle, polygon, and freehand selection logic with normalized coordinates. | Potentially reusable interaction logic. | Old crop types, canvas coordinate assumptions. | Coordinate conventions and editing behavior may conflict with the new UI. | Extract coordinate math and hooks separately from old crop screens. |
| frontend/features/page-thumbnails/ | Page thumbnail cards/list and thumbnail loading. | Partly generic. | Old page APIs and project page records. | Would trigger old API contracts if copied directly. | Keep visual concepts only; replace service/data contracts. |
| backend/app/jobs/job_repository.py | Database-backed queue claim, completion, failure, and retry behavior. | Generic and retained in cleaned form. | background_jobs table, database adapter. | Concurrency behavior must be load-tested on PostgreSQL before production use. | Register only new job types through the clean worker registry. |
| backend/app/storage/storage_service.py | Unified local/R2 file operations. | Generic and retained. | LocalStorage, R2Storage, settings. | Path-to-key conventions and temporary-file lifecycle require future policy. | Use as infrastructure; add new feature-specific directories only when the new design is known. |
| backend/app/core/security.py | Filename and security helpers. | Generic and retained. | Python standard library. | Validate against future upload threat model. | Reuse through shared validation dependencies. |
| backend/app/boq/exporters/pdf_boq_exporter.py | Formats BOQ reports as PDF. | Tightly coupled to old BOQ schemas and report layout. | ReportLab, BOQ models/templates. | Direct reuse would bring back the old data model and UI assumptions. | Treat only as visual/reference material; design a new export contract first. |
| backend/app/boq/exporters/excel_boq_exporter.py | Formats BOQ reports as Excel. | Tightly coupled to old BOQ rows. | openpyxl, BOQ models. | Column definitions and grouping are old-workflow specific. | Extract formatting patterns only after new output requirements are approved. |
